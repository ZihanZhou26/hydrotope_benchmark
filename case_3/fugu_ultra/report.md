# Closed-form A_n in the two-minus sector

Worked only from `prompt.md`, `OnShellBG.m`, and data generated by running the
code. All scripts/outputs live in this `fugu_ultra/` directory.

## 1. The formula

Sector: `sigma = (-1, -1, +1, ..., +1)` with all frequencies incoming and
on-shell, i.e.

    sum_i omega_i = 0,
    -omega_1^2 - omega_2^2 + sum_{j>=3} omega_j^2 = 0.

In this code each leg's momentum sign is fixed by sigma
(`k_i = sigma_i*omega_i^2/g`), so `|k_i| = omega_i^2/g`. Because BG
propagators contain `|k_S| = |sum_i sigma_i*omega_i^2|`, the amplitude is a
**piecewise-polynomial (spline)** in the squared frequencies. The compact way
to write it uses the truncated power `[x]_+ = max(x, 0)`.

Define, for a set R of "plus" legs of size m = n-3,

    T_m(t; {a_j}) = sum_{S subset R} (-1)^|S| * [ t - sum_{j in S} a_j ]_+^m .

**Two-minus amplitude (physical channel produced by `MakeKinematics` for
arbitrary on-shell free frequencies):**

    A_n = i * 2^(n-1) / g^(n-3) * omega_1 * omega_2
            * T_{n-3}( omega_2^2 ; { omega_j^2 : j = 3..n-1 } )

with R = {3, ..., n-1} (the n-3 positive plus-legs). Here, in the standard
conventions of `MakeKinematics` (positive free frequencies omega_2..omega_{n-1},
solved legs omega_1 < 0 and omega_n < 0), leg 1 and leg 2 are the two
sigma = -1 legs.

Special cases / sanity:

- n = 4:  A_4 = i * (8/g) * omega_1 * omega_2 * min(omega_2^2, omega_3^2).
- If omega_2 is the smallest scale (omega_2^2 <= omega_j^2 for all j=3..n-1),
  the truncated power collapses to a single monomial:

      A_n = i * 2^(n-1) / g^(n-3) * omega_1 * omega_2^(2n-5).

- g-dependence: A_n scales as 1/g^(n-3) (verified at g = 1, 3/2, 2).

regimes (one frequency ~100x larger or ~100x smaller than the rest) and

zero-momentum current) at the exact on-shell point. `final_verify.wls`
evaluates A_4 as the regular eps -> 0 limit of an energy-conserving
deformation `omega = {-w3-eps, w2, w3, -w2+eps}`; the limit is finite and
matches the formula.

## 3. Reasoning

1. Ran BG at n = 5, 6, 7 in prompt-style kinematics; when omega_2 was the
   smallest same-sign scale the data collapsed to the monomial
   `i 2^(n-1) omega_1 omega_2^(2n-5) / g^(n-3)`.
2. That monomial broke when omega_2 was not the smallest scale, so I reduced
   the n = 5 BG output symbolically in fixed sign/magnitude chambers. The
   chamber pieces were exactly the inclusion-exclusion terms of a truncated
   power `T_m(t) = sum_S (-1)^|S| [t - sum_S a]_+^m`. This is the spline
   structure forced by the `|k_S|` absolute values in the propagators.
3. Substituting the truncated-power factor reproduced exact BG at every
   tested rational point through n = 7, across all magnitude regimes and g.

## 4. Scope / honest caveat

- For **arbitrary on-shell free frequencies fed to `MakeKinematics`** (the
  prompt's setup), energy conservation forces mixed signs, and the solved
  legs come out negative; the kinematics always land in the single physical
  channel above (verified: 100% of 500 random positive-free-frequency points
  for each n = 4..8). The boxed formula is exact there.
- If one instead hand-builds kinematics by flipping the **signs** of the
  free frequencies into other sign chambers, the spline lands in a different
  cell and the closed form must use the matching leg as `p` and the matching
  same-sign plus-leg set as `R` (T_m over those legs). I confirmed the
  general spline structure persists but did not enumerate every sign cell
  into one universal expression; the channel-selection rule is: pick the
  sigma=- leg `p` whose frequency-sign is shared by exactly n-3 of the plus
  legs (set R), let `q` be the other sigma=- leg, then
  `A_n = i 2^(n-1) q p T_{n-3}(p^2; {omega_j^2: j in R}) / g^(n-3)`.
