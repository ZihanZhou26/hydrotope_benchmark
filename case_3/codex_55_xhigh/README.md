# Two-minus closed form

See `result.md` for the formula, derivation notes, and verification table.
`verify_formula.m` contains the independent Wolfram check used to compare the
closed form against `BGAmplitude`.
`scratch_run_code.md` records the exploratory commands and code snippets used
while deriving and testing the formula.
`chronological_log.md` reconstructs the visible message/command/output timeline.
`original_visible_thinking_log.md` and `original_visible_session_events.jsonl`
extract the original visible solve-turn transcript directly from the Codex
session store.
`thinking_log.pdf` is the rewritten thinking log in the same title/abstract/prose
style as `thinking_log_format/example_chain_of_thought.pdf`; `thinking_log.tex`
is its LaTeX source.
