# Open research run — start here

This directory is ONE open-problem research run (the three-minus sector). To do it:

1. Read `RUN.md` in full -- it is the authoritative task specification.
2. Build and query the oracle `bg.cpp` for all amplitude values; you MAY use
   online search and the literature (this is an open problem).
3. Follow the recursive process-improvement scaffold (keep `discovery_policy.md`,
   `LEDGER.md`, `policy_history.md`, `ACTION_TRACE.jsonl`, `POLICY_AUDIT.md`
   live, not as an end-of-run dump), and produce every Required Deliverable.

For heavy computation you may submit jobs to the Typhon cluster (see
`IAS_COMPUTE_GUIDE.md`). No answer to this problem is known; derive and validate everything against the
oracle.
